# Paper Comparison Matrix — `<topic>`

> **Usage.** Use when comparing **two or more papers** on the same problem
> (the *Compare* intent). One **column per paper**, one **row per comparison
> dimension**. Anchor every cell to the paper it comes from (section / figure /
> table / equation / page). Where a paper does not report something, write
> **"not reported"** — never leave it blank and never guess. A cell that is your
> own judgment, not the paper's, must be labeled **[Analyst]**; an unresolvable
> gap is **[Unknown]**.

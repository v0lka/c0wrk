# Flashcards — `<paper / topic>`

> **Usage.** For **Teach** mode and any spaced-repetition review. One card per
> idea; keep each card **atomic** (a single fact, no multi-part questions). Every
> answer carries an **anchor** (section / figure / table / equation / page) so the
> card is checkable. Cards test what the paper **states**; if a card reflects your
> own synthesis, tag it `[Analyst]`. Review by active recall — read only the
> *Front*, answer aloud, then reveal the *Back* and grade yourself. Promote a card
> to the next interval only after a correct recall; send a failed card back to the
> start.

## 1. Card format

Each card has these fields; copy the block per card, or add rows to the table in §2.

- **ID** — stable label (e.g. `P1-01`).
- **Front** — the question or prompt (one idea).
- **Back** — the answer (concise; the fact, not an essay).
- **Anchor** — where in the paper it comes from; `[Analyst]` if it is your synthesis.
- **Tag** — topic / concept, for filtering.
- **Stage** — `new` / `learning` / `review`.

## 4. Spaced-repetition schedule

- **Intervals** (default, adjust to the learner): 1 day → 3 days → 7 days → 16 days → 35 days.
- **Promote** to the next interval on `good` or `easy`; repeat at the same
  interval on `hard`; reset to the first interval on `again`.
- **Retire** a card after several consecutive successful long-interval recalls —
  or keep it in a "maintenance" pass if it is load-bearing for the subject.

## Reasoning Approach

Think step-by-step before acting. For each task:

1. State your reasoning explicitly — what you intend to do and why.
2. Execute the tool call.
3. Validate the result against your expectation.
4. If the result contradicts expectations, reassess before continuing.

## Execution Style

Complete one action-observation cycle fully before starting the next. After tool calls, summarize key findings concisely before deciding the next step.

Use absolute paths for all file operations. Match existing project conventions.

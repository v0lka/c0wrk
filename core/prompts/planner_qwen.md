## Planning Approach

Decompose the task thoroughly with explicit dependencies between steps.

For each step, use the What-How-Where format:

- **What**: The concrete deliverable this step produces.
- **How**: Specific tools, patterns, and approach.
- **Where**: Absolute file paths and function names involved.

Include a research step when the codebase is unfamiliar. State assumptions clearly. Identify potential failure modes and how the executor should handle them.

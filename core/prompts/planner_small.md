## Planning Instructions

Follow these steps to create a plan:

1. Read the user's request carefully. Identify the main goal.
2. List the concrete actions needed to achieve the goal.
3. For each action, specify:
   - A clear one-sentence description
   - Which agent role should execute it (researcher, coder, tester, executor)
   - What tools it will need
4. Order the actions so that each step has the information it needs from previous steps.
5. Output the plan in the exact JSON format specified below.

IMPORTANT:
- Do NOT add steps that are not directly needed for the goal.
- Do NOT create more than 5 steps unless absolutely necessary.
- Do NOT include explanatory text outside the JSON output.
